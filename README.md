# Cyber-Fox

Облачная платформа управления компьютерными клубами: учёт времени, биллинг, касса и аналитика по
сети залов.

## Состав

```
apps/server    NestJS + PostgreSQL: сессии, биллинг, права, веб-сокеты
apps/admin     React + Vite: кассовый экран и карта зала
apps/agent     Electron: блокировка игрового ПК и экран гостя
packages/shared Общие типы и контракты событий
```

## Что уже работает

**Учёт времени и деньги**
- Зоны зала, тарифы поминутные и пакетные, тарифы по времени суток
- Пакеты минут на аккаунте гостя: тратятся за несколько визитов, привязаны к клубу и зоне
- Автопереход на поминутный тариф при исчерпании минут — без разрыва сессии
- Игра в долг до лимита клуба, блокировка ровно на лимите
- Анонимная посадка по предоплате

**Смена и зал**
- Оба пути входа: гость сам по телефону и PIN, администратор со стойки
- Карта зала с живым состоянием машин, пересадка, пауза, завершение
- Смены со сверкой кассы, бар с остатками и маржой, бонусы за потраченное
- Карточка гостя с историей визитов и движением по счёту

**Сеть клубов**
- Управление залами и сотрудниками, роли владельца и управляющего
- Сводные отчёты: выручка и загрузка по залам, прибыльность машин, часы пик
- Общий кошелёк сети с отчётом по межклубному взаимозачёту

**Работа без интернета**
- Оплаченная сессия доигрывается по монотонным часам машины
- Списывается только время, подтверждённое агентом: система скорее недосчитает,
  чем возьмёт с гостя за время, которого не было

**Продажа чужим клубам**
- Самостоятельная регистрация с пробным периодом: зал готов к работе сразу
- Подписка с лимитом машин, счета, льготный период вместо резкой остановки
- Перенос гостей, машин и тарифов из выгрузок Senet, SmartShell и Excel

## Запуск

Нужны Node.js 20+, pnpm и PostgreSQL 14+.

```bash
pnpm install

# 1. База
cp apps/server/.env.example apps/server/.env   # пропишите DATABASE_URL и JWT_SECRET
pnpm --filter @cyberfox/server prisma:migrate
pnpm --filter @cyberfox/server seed

# 2. Сервер
pnpm dev:server        # http://localhost:3000

# 3. Кассовый экран
pnpm dev:admin         # http://localhost:5173

# 4. Агент на игровом ПК
CYBERFOX_PAIRING_TOKEN=<код из админки> pnpm dev:agent
```

Сид создаёт клуб на 50 машин (40 «Стандарт», 10 VIP), тарифы, сотрудников и тестового гостя:

- владелец сети: `owner@cyberfox.kz`, пароль `cyberfox123`
- администратор зала: `admin@cyberfox.kz`, пароль `cyberfox123`
- гость: `+77010000001`, PIN `1234`, баланс 2000 ₸
- коды привязки машин: `seed-pair-std-1`…`seed-pair-std-40`, `seed-pair-vip-1`…`seed-pair-vip-10`

## Установка в клуб

Всё вместе — база, сервер, кассовый экран за HTTPS и ежедневный бэкап:

```bash
cp deploy/env.example .env      # домен, пароль базы, JWT_SECRET
docker compose up -d
```

Порядок первого дня в зале, проверки первой смены и честный список того, чего
ещё нет для чужого клуба — в [docs/deploy.md](docs/deploy.md).

Пилот в локальной сети клуба, без домена и HTTPS — сервер прямо в зале:

```powershell
docker compose -f docker-compose.yml -f deploy\lan.yml up -d
```

Под Windows это `deploy\windows\start.cmd`; подробности —
[docs/install-windows.md](docs/install-windows.md).

## Проверки

```bash
pnpm -r typecheck
pnpm exec vitest run
```

Расчёт денег вынесен в чистые функции (`apps/server/src/billing/billing.rules.ts`) и покрыт тестами
на конкретных числах: пограничные случаи вроде «минута дороже кредита» или «пакет сгорел посреди
игры» проверяются без поднятой базы.

## Единицы измерения

Все суммы в базе и в API — целые числа **в тиын** (1/100 ₸). Поминутная цена часто получается
делением часовой, и дробные значения за смену расходятся с кассой. В тенге суммы переводятся только
при показе.
