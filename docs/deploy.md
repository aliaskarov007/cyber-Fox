# Пилот в зале

Как поставить Cyber-Fox в реальный клуб и проверить его на живых гостях.
Документ рассчитан на первый зал — свой, где ошибку можно исправить, не теряя
клиента.

## 1. Главное правило пилота

**Первую неделю прежняя система остаётся включённой.** Не как запасной план на
бумаге, а работающей: сервер жив, лицензия не сдана, администратор помнит, как
в неё вернуться. Переключение всего зала разом — это ставка на то, что мы
ничего не забыли, а забыли мы наверняка.

Порядок: 3–5 машин одной зоны → неделя → вся зона → неделя → зал.

Две системы на одной машине одновременно ставить нельзя: две блокировки будут
драться за фокус, и проиграет гость. Пилотные ПК выводятся из прежней системы
до установки агента.

## 2. Что нужно до выезда в зал

| Что | Зачем |
|---|---|
| Машина под сервер | Облачный VPS: 2 ядра, 4 ГБ памяти, 40 ГБ диска — с запасом на 100 машин |
| Домен | Например `club.вашдомен.kz`, A-записью на этот VPS. Без домена не будет HTTPS |
| Docker | `docker` и `docker compose` на сервере |
| Машина с Windows | Чтобы собрать установщик агента |
| Список машин зала | Названия и зоны — их же увидит администратор в карте зала |
| Выгрузка из прежней системы | Гости с балансами, тарифы. Формат — CSV или Excel |

Ставите на Windows или держите сервер прямо в зале, без домена? Тогда
[install-windows.md](install-windows.md) — там тот же порядок, но для
локальной сети.

## 3. Сервер

```sh
git clone <репозиторий> cyber-fox && cd cyber-fox
cp deploy/env.example .env
```

В `.env` заполните обязательное:

- `CYBERFOX_DOMAIN` — домен клуба; на него Caddy сам получит сертификат;
- `ALLOWED_ORIGINS` — тот же домен со схемой `https://`;
- `POSTGRES_PASSWORD` и `JWT_SECRET` — оба длинные и разные:
  `openssl rand -hex 32`;
- `TZ` — часовой пояс клуба, по нему считаются смены и ночные тарифы.

```sh
docker compose up -d
docker compose logs -f server   # ждём «Nest application successfully started»
```

Проверка: `https://ваш-домен` открывает экран входа, замок в адресной строке
без предупреждений. Если сертификат не выпустился — почти всегда домен ещё не
указывает на этот сервер или закрыт 80-й порт, через него проходит проверка.

**Смена `JWT_SECRET` разлогинивает всех.** Задайте его один раз до пилота.

## 4. Клуб и данные

1. На экране входа — «Зарегистрировать клуб». Заводится владелец, клуб и
   пробный период.
2. «Настройки» — зоны зала (VIP, Стандарт), затем машины.
3. «Тарифы» — поминутные и пакеты, отдельно по зонам. Заведите ровно те же
   цены, что в прежней системе: пилот проверяет систему, а не новый прайс.
4. «Подключение» → «Перенос из прежней системы» — вставьте выгрузку гостей.
   Загружать можно повторно: строки сопоставляются по телефону, дубли не
   появятся. Пропущенные строки показываются поимённо — просмотрите их, это
   те гости, чьи деньги иначе потеряются.

Сверьте после переноса: число гостей и сумму балансов. Расхождение здесь —
это чужие деньги, и заметить его нужно до первой смены, а не в конце месяца.

## 5. Агенты на игровых машинах

Собрать установщик (на машине с Windows, из папки репозитория):

```sh
pnpm install
pnpm --filter @cyberfox/agent pack:win
```

Готовый файл — в `apps/agent/release`. На каждой пилотной машине:

1. Установить агент (обычный установщик, «Далее»).
2. Агент запустится сам и спросит адрес сервера и код привязки. Код напечатан
   в админке на экране «Подключение», рядом с названием ПК. Каждый код
   подходит только к одной машине.
3. Проверить, что машина появилась в карте зала как «на связи».
4. От имени администратора один раз поставить сторожа:
   `powershell -ExecutionPolicy Bypass -File deploy\agent\install-watchdog.ps1`

Сторож раз в минуту поднимает агента, если процесс сняли через диспетчер
задач. Блокировка перехватывает Alt+F4, Alt+Tab и клавишу Windows, но
диспетчер закрывает процесс мимо приложения — сторож делает это бессмысленным.

## 6. Что проверить в первую смену

Пройдите это сами, до гостей. Каждый пункт занимает минуту, а найденное на
пустом зале стоит несравнимо дешевле найденного при очереди на стойке.

| Проверка | Что должно произойти |
|---|---|
| Открыть смену, посадить гостя со стойки | Машина разблокировалась, таймер пошёл |
| Гость входит сам по телефону и PIN | То же самое, без администратора |
| Дать закончиться пакету | Игра **не прерывается**, включается поминутный тариф, гость видит сообщение |
| Довести баланс до нуля | Игра продолжается в долг до 100 ₸, потом экран блокируется |
| Пересадить гостя в другую зону | Время не теряется, остаток пакета остаётся за прежней зоной |
| Пополнить наличными и онлайн | Обе суммы попали в кассу смены |
| Выдернуть интернет на 10 минут | Оплаченная игра идёт дальше; после возврата связи списались только отыгранные минуты |
| Закрыть смену | Сверка кассы сходится с ящиком |

Отдельно проверьте попытки обхода на одной машине: диспетчер задач, Alt+F4,
перезагрузка посреди сессии. Всё это гости пробуют в первую же неделю.

## 7. Ежедневное

- **Бэкап** делается сам, раз в сутки, в папку `backups`. Раз в неделю
  скачивайте свежий файл с сервера: бэкап, лежащий на той же машине, не
  спасает от потери машины.
- **Восстановление** проверьте один раз, до пилота, а не в день аварии:
  ```sh
  gunzip -c backups/cyberfox-ГГГГ-ММ-ДД-ЧЧММ.sql.gz | \
    docker compose exec -T db psql -U cyberfox -d cyberfox
  ```
- **Обновление**: `git pull && docker compose up -d --build`. Миграции
  применяются при старте сервера сами. Обновляйтесь между сменами.

## 8. Чего ещё нет — знать до пилота

Честный список. Ничто из этого не мешает проверить систему в своём зале, но
каждое всплывёт при продаже чужому клубу.

**Блокировка держит обычного гостя, а не подготовленного.** Загрузка в
безопасном режиме, вторая учётная запись Windows, загрузочная флешка — всё это
обходит агента. Настоящее решение — служба и запрет загрузки с внешних
носителей в BIOS с паролем. Для своего зала хватает сторожа; для чужого —
нет.

**Установщик не подписан.** Windows покажет предупреждение SmartScreen при
установке на каждой машине. Для сорока своих машин это сорок нажатий
«Всё равно установить», для чужого клуба — повод не ставить вовсе. Нужен
сертификат подписи кода.

**У агента нет своей иконки** — используется стандартная электронная. Мелочь,
которая на чужом ПК читается как «поделка».

**Новые сессии во время обрыва связи не запускаются.** Оплаченная игра
доигрывается, но посадить нового гостя без интернета нельзя. Решение —
локальный узел, отложен намеренно (см. [offline.md](offline.md), раздел 2).
Если у клуба связь падает часто, сначала поставьте 4G-модем запасным каналом.

**Онлайн-оплата требует настоящего провайдера.** Сейчас `PAYMENT_PROVIDER` по
умолчанию `manual`: кассир отмечает переводы вручную. Подключение банка —
отдельная работа с договором.

**Пустой клуб не подсказывает, что делать дальше.** Сразу после регистрации
владелец видит пустую карту зала без единой подсказки. Для своего зала это
неважно, для чужого — первое впечатление.

**Обновление агента ручное.** Установщик придётся прогонять по машинам заново.
Автообновление — отдельная задача.
