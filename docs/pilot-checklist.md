# Чеклист: три машины

Один лист на день установки. Подробности — в
[install-windows.md](install-windows.md) и [deploy.md](deploy.md).

## До зала

- [ ] На пилотном ноутбуке установлен Docker Desktop, показывает «Engine running»
- [ ] Отключён спящий режим и засыпание при закрытой крышке
- [ ] За ноутбуком закреплён постоянный адрес в роутере (иначе после
      перезагрузки все три агента разом потеряют сервер)
- [ ] Склеен установщик агента, контрольная сумма совпала
- [ ] Выбраны три машины **одной зоны**, стоящие рядом: их будет видно с стойки
- [ ] Эти три машины выведены из прежней системы — две блокировки на одном ПК
      подерутся за фокус

## Сервер

- [ ] `git clone`, `Copy-Item deploy\env.example .env`
- [ ] В `.env` заполнены `POSTGRES_PASSWORD` и `JWT_SECRET` — длинные и разные
- [ ] `deploy\windows\start.cmd` отработал, показал адрес вида `http://192.168.1.50:8080`
- [ ] Адрес открывается с другого компьютера в зале, не только с самого ноутбука
- [ ] Адрес записан на бумажке — его вводить на каждой машине

## Клуб

- [ ] Зарегистрирован клуб, вход владельцем работает
- [ ] Зона переименована под реальную (или добавлена нужная)
- [ ] Заведены три машины с теми же названиями, что написаны на корпусах
- [ ] Тариф-заготовка исправлен на **вашу текущую цену** — пилот проверяет
      систему, а не новый прайс
- [ ] Если есть пакеты — заведены с теми же условиями, что сейчас
- [ ] Заведён сотрудник для администратора смены, он вошёл под собой

## Гости

- [ ] Выгрузка из прежней системы загружена через «Подключение»
- [ ] Сверено: число гостей и **сумма балансов** совпадают с прежней системой
- [ ] Просмотрены пропущенные строки — это гости, чьи деньги иначе потеряются

Расхождение по деньгам ловится здесь, а не в конце месяца.

## Каждая из трёх машин

Зал на бездисковой загрузке устроен иначе: агент ставится в общий образ, а не
на каждую машину, и коды привязки не нужны. Порядок — в
[install-diskless.md](install-diskless.md), раздел 7.

- [ ] Установщик прошёл (SmartScreen → «Подробнее» → «Выполнить в любом случае»)
- [ ] Введён адрес сервера и код привязки **этой** машины
- [ ] В карте зала машина показана «на связи» и с правильным названием
- [ ] Поставлен сторож: `powershell -ExecutionPolicy Bypass -File deploy\agent\install-watchdog.ps1`
- [ ] ПК перезагружен — агент поднялся сам и блокировка на месте

## Проверка до гостей

Пройти на одной машине, до открытия смены.

- [ ] Открыта смена, гость посажен со стойки — экран разблокировался, таймер пошёл
- [ ] Гость вошёл сам по телефону и PIN
- [ ] Пакет закончился — игра **не прервалась**, включился поминутный тариф
- [ ] Баланс ушёл в ноль — игра продолжилась в долг, потом экран заблокировался
- [ ] Пополнение наличными попало в кассу смены
- [ ] Диспетчер задач: агент снят — через минуту блокировка вернулась
- [ ] Alt+F4 и клавиша Windows блокировку не убирают
- [ ] Перезагрузка посреди сессии — после входа игра продолжается
- [ ] Wi-Fi выключен на 10 минут — оплаченная игра идёт; после включения
      списались только отыгранные минуты
- [ ] Смена закрыта, сверка кассы сошлась

## Первая неделя

- [ ] Прежняя система остаётся включённой и рабочей
- [ ] Администратор знает, как вернуться на неё, и что делать при вопросах гостя
- [ ] Раз в день: беглый взгляд на отчёт смены — сходится ли с ящиком
- [ ] Раз в неделю: свежий файл из папки `backups` скопирован с ноутбука

## Если что-то пошло не так

| Симптом | Куда смотреть |
|---|---|
| Машина не появляется в зале | Адрес сервера и код привязки на этой машине; брандмауэр на ноутбуке |
| Все машины разом отвалились | Ноутбук уснул, сменился IP, или Docker Desktop не запущен |
| Гость не может войти | Открыта ли смена; есть ли гость в базе после переноса |
| Экран не блокируется | Запущен ли агент; поставлен ли сторож |
| Деньги не сходятся | Отчёт смены, движение по счёту в карточке гостя |

Откат: остановить агент на машине, вернуть её в прежнюю систему.
Данные Cyber-Fox при этом остаются — `stop.cmd` ничего не стирает.
